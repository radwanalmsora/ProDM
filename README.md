# ProDM — مدير تحميل محلي لأندرويد

## البناء عبر GitHub Actions
1. أنشئ مستودعاً جديداً على GitHub (Private مناسب).
2. ارفع **محتوى** هذا المجلد كما هو (مع مجلد `.github`).
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (يعمل تلقائياً عند أول رفع).
4. بعد انتهاء البناء نزّل الملف من **Artifacts** ← `ProDM-apk` وفك الضغط.
   - `app-release.apk` (أصغر وأسرع) أو `app-debug.apk` (احتياطي).

## ملاحظات
- الملفات تُحفظ في: Downloads/ProDM/<التصنيف>
- أيقونة التطبيق Adaptive Icon داخل `res/`، ونسخة PNG بحجم 512 في مجلد `icons/`.
- إن فشل البناء أرسل لي نص الخطأ من سجل Actions وأصلحه لك.
